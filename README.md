# Perfumería Los Cracks

Sistema de gestión de perfumería desarrollado en PHP y MySQL.

## Funcionalidades
- Gestión de clientes
- Gestión de proveedores
- Gestión de perfumes
- Registro de ventas

## Notas
- Es necesario tener MySQL activo (y Apache si es para uso local) en XAMPP.
- Si el sistema no carga, verificar la ruta del proyecto dentro de `htdocs`.
- Las imágenes deben estar en la misma carpeta o con la ruta correcta en el código.
